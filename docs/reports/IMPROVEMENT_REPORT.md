# SUMO 500 改善実施レポート

実施日: 2026-11-25

## 1. 発見した原因

調査対象は `src/game.js`、`src/data.js`、`src/main.js`、`src/physics.test.js` です。

- 初期配置の `likelyOpponentResponses` は `analyzeOpening()` 内で作られていましたが、戦術スコアでは実質的に使われておらず、初期の後退予測が direct / zigzag の選択に十分反映されていませんでした。
- 戦術切替に最低保持時間・ヒステリシス・有意差条件がなく、短時間のスコア差で戦術が切り替わりやすい状態でした。
- Escape は中心方向を目標にするだけで、接触時の相手位置・相手速度による押し返しを十分考慮していませんでした。また、Escape 選択後も通常戦術へすぐ戻る余地がありました。
- 試合結果は、実行条件を満たした戦術のうち貢献スコア最大の1件にだけ評価されていました。複数戦術を実際に使った試合で、他の戦術の貢献を記録できていませんでした。

## 2. 実施した修正

### 初期Zigzag選択

初期配置の後退予測、角度有利、距離、空きスペースを `selectTactic()` のスコアへ接続しました。後退が予測でき、Zigzagの距離・空間条件を満たす場合だけ加点するため、無条件にZigzagへ固定する変更ではありません。

### 戦術切替の安定化

- 現在戦術に保持ボーナスを追加。
- 実行時間に基づく最低保持時間を追加。
- 切替候補は、現在戦術を一定以上上回るスコア差がある場合に限定。
- Escape は選択後の短い保護時間を設定。
- 土俵際の緊急条件では保持制約よりEscapeを優先。

### Escape制御

Escape中は土俵中心方向を基本とし、接触または相手の速度が高い場合は、中心方向と相手から離れる方向を合成した脱出ベクトルを使います。drive と turnScale もEscape専用に強化しました。

### 学習評価

実行条件を満たした全戦術について、稼働時間と接触時間から貢献度を計算し、試合結果を貢献度に応じて個別に評価するよう変更しました。根拠が薄い戦術への優先度・パラメータ更新は小さくなります。既存の保存キー `sumo500-ai-v2` と既存のバージョン移行処理は維持しています。

## 4. 追加・変更したテスト

以下を追加しました。

- 相手がまだ動いていない初期状態でも、後退予測がZigzag選択へ接続されること。
- 戦術保持時間中に短時間のスコア差で切り替わらないこと。
- 複数戦術へ貢献度付きで結果を記録し、低貢献戦術の更新が小さいこと。

## 7. 戦術ごとの改善・悪化

- Zigzag: 初期後退予測が選択スコアへ接続され、回帰テストで確認済み。ただし、対戦比較では後退相手への勝利は確認できず、実戦性能の改善は未確定です。
- Escape: 接触時の脱出方向と保持時間を改善。物理単体テストは通過しましたが、Escape単体の多数実戦ケースは今後追加確認が必要です。
- 戦術切替: 全5相手タイプで平均切替回数が減少しました。これは安定化の効果として確認できました。
- 学習評価: 複数戦術へ貢献度を分配する仕組みを追加し、1戦術への丸ごとの誤帰属を避けました。
- 総合勝率: 変更後に一律の改善は確認できませんでした。特に後退相手は変更前より悪化しているため、改善済みとは判断しません。

## 8. 学習データの保持状況

既存の `sumo500-ai-v2` を読み込み、既存のバージョン移行処理を継続利用します。既存の保存形式を削除・初期化していません。既存保存データの読み込み・追記テストも成功しています。

## 9. 未解決の問題

- 後退相手に対する実戦勝率は改善していません。
- ヘッドレス比較では引き分けが多く、現行の相手AIモデルが実機の押し合いを十分に再現しているか追加検証が必要です。
- Escapeの接触中制御は改善しましたが、相手が縁側から押す複数角度・複数速度の専用対戦ケースが不足しています。
- 学習更新の長期安定性（多数試合後に基本戦術が弱くならないか）は未検証です。

## 10. 実機・ブラウザで追加確認が必要な項目

- 実機相当のタッチ操作で左右輪入力が正しく伝わること。
- 土俵際でEscape中に相手から押された場合の場外率。
- 初期配置を複数seedで生成した場合のZigzag選択率と勝率。
- 同じ学習データで、学習前・学習後の実機対戦を同数比較すること。
- 旋回・側面・斜め接触時の押し合いと場外判定。

結論として、今回の変更は「初期予測の接続」「短時間切替の抑制」「Escape制御」「複数戦術評価」を実装し、テストとビルドを通過しました。一方、対戦勝率は一律改善しておらず、現時点で実戦性能が改善したとは断定しません。
