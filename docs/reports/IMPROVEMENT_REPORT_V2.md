# SUMO 500 第2次改善実装レポート

実施日: 2026-11-25

## 結論

前回改善版をベースにコードを変更し、回帰テスト・本番ビルド・同一条件のヘッドレス対戦を実施しました。第2次版では、後退型相手への対応が大きく改善しました。後退型30試合のAI勝利は前回版の2勝から28勝へ増え、全5タイプ150試合ではAI勝利が3勝から42勝へ、AI敗北が13敗から3敗へ減少しました。

ただし、場外発生率は「勝敗が決まった試合」が増えた影響も含めて前回平均10.7%から第2次版平均30.0%へ増えています。Escapeの機体全体余裕は改善しましたが、攻撃時の場外リスクは残っています。したがって、実戦性能は主に後退型・カウンター型・不規則型で改善した一方、全状況で安全性まで解決したとは報告しません。

## 実装した変更

### 後退型相手への対応

相手のAIから離れる速度を正しく後退速度として判定するようにしました。以前は相手の速度をAI方向との内積で判定する符号が逆で、実際に後退している相手を後退として認識できないケースがありました。

`opponentPrediction()` を追加し、相手の速度、AIから離れる速度、横方向速度、旋回速度、距離から短期未来位置を推定します。Zigzagの操舵は、相手の現在位置だけでなく、この未来位置と旋回による横ずれを使います。後退確信度と旋回確信度が低い場合は従来の配置ベース操舵に戻るため、無条件にZigzagへ固定していません。

### Escape

Escapeの優先度を中心位置ではなく、実際の機体フットプリントの最小土俵余裕で決めるようにしました。接触時は中心方向と相手から離れる方向を合成し、危険度が高いほど目標距離と旋回強度を増やします。

Escapeは試合の勝敗とは独立して、試行回数、機体全体の余裕が10以上増えた回数、失敗回数、直近の余裕変化を `escapeStats` として保存します。成長画面にも回復率を表示します。

### 戦術切替

前回導入した最低保持時間、ヒステリシス、有意差条件は維持しました。加えて、静止中の相手がAIを向いているだけではcounterを選ばないようにし、実際の接近速度または土俵際条件を満たす場合にcounterを強く選ぶようにしました。これにより、初期配置でcounterに固定されて攻撃機会を失う問題を抑えています。

### 学習評価

戦術の選択時間と接触時間だけでなく、戦術開始時点からの距離変化、AIの機体全体土俵余裕の変化、相手方向への角度差の変化、接触状態を記録します。これらを `stateChange` と `progressScore` として貢献度評価に加えました。既存の複数戦術への貢献度評価は維持しています。

基本戦術・既存の保存キー `sumo500-ai-v2`・既存学習データの移行処理は維持しました。第2次変更前の状態は `/home/ubuntu/work/sumo500-second-before/` に保存しています。

## 対戦比較

前回改善版と第2次改善版を、同じseed系列、同じ初期配置、同じ物理条件で比較しました。相手タイプは直進型、後退型、旋回型、カウンター型、不規則型で、各30試合、合計150試合です。

| 相手 | 前回 AI勝/敗/分 | 第2次 AI勝/敗/分 | 平均時間 前回→第2次 | 平均切替 前回→第2次 |
|---|---:|---:|---:|---:|
| 直進型 | 0 / 2 / 28 | 2 / 0 / 28 | 54.13→54.13秒 | 0.97→0.93 |
| 後退型 | 2 / 6 / 22 | 28 / 0 / 2 | 42.53→3.87秒 | 0.73→0.03 |
| 旋回型 | 1 / 0 / 29 | 0 / 2 / 28 | 56.07→54.13秒 | 0.97→0.80 |

| 不規則型 | 0 / 4 / 26 | 7 / 1 / 22 | 50.27→42.53秒 | 0.90→0.70 |
| **合計** | **3 / 13 / 134** | **42 / 3 / 105** | — | — |

勝率は前回2.0%（3/150）から第2次版28.0%（42/150）へ改善しました。後退型ではZigzagの実行が28件で、そのうち28件が実行前後の状態改善または接触を記録しました。これは後退相手への未来位置予測が戦術制御に接続されたことを示しますが、勝利と状態改善は同義ではないため、Zigzagの成功率を勝率と同一視していません。

場外発生率は、直進6.7%→6.7%、後退26.7%→93.3%、旋回3.3%→6.7%、カウンター3.3%→16.7%、不規則13.3%→26.7%でした。後退型の短時間勝利が増えたため、場外率は高くなっています。これは勝利時の相手場外も含む集計であり、AI自身の場外だけを意味しません。AI自身の場外と相手場外を分離する実機ログは次の改善候補です。

Escapeの独立回復は第2次版で、直進28/28、後退1/1、旋回24/24、カウンター25/25、不規則21/21でした。前回版は独立Escape統計を持たないため、前回の0件は失敗を意味せず、比較可能な基準値ではありません。

## 未解決の問題

攻撃時のAI自身の場外リスクはまだ残っています。特に、後退相手への勝利が増えた一方で、場外発生率の意味をAI自身・相手別に分離できていません。現行のヘッドレス相手モデルは、実機の摩擦、接触角度、操作者入力を完全には再現しないため、実機相当のタッチ操作と複数初期配置で追加確認が必要です。

また、学習データを多数試合にわたって蓄積したとき、ZigzagやEscapeの優先度が過剰に上がらないかは別途長期テストが必要です。今回の実装では既存の優先度上限、貢献度の最低重み、複数戦術分配を維持していますが、長期安定性の証明まではできていません。
